01 • AKURASI RENDAH

Human Error Plotting KMS Manual di Kertas

  • Kader harus mencari titik koordinat BB & Umur di lembar grafik kertas yang sangat padat.
  • Salah meletakkan titik grafik menyebabkan false-negative (balita gagal tumbuh tidak terdeteksi).
  • Deviasi plotting manual di posyandu pelosok tercatat mencapai 25% - 30% (Jurnal Gizi Indonesia).
⚠️ 30% Deviasi Data Pengukuran
02 • BIROKRASI LAMBAT

Beban Administrasi & Pelaporan Lambat

  • Data dicatat berulang di buku register, KMS fisik, lalu direkap berhari-hari.
  • Rata-rata 5-8 jam kader tersita hanya untuk menyalin dan merekap data penimbangan.
  • Puskesmas baru menerima rekap 2-3 minggu kemudian; intervensi medis sudah sangat terlambat.
⏳ Terlambat 2-3 Minggu ke Dinkes
03 • DEFISIT KONSELING

Vakum Preskripsi Gizi Bahan Pangan Lokal

  • Kader tidak dibekali alat bantu takaran gizi spesifik saat mendapati anak berisiko.
  • Nasihat nutrisi sering kali bersifat umum tanpa arahan bahan murah lokal.
  • Orang tua prasejahtera mengira makanan bergizi harus mahal (susu formula / daging).

ARSITEKTUR & FITUR UTAMA

Empat Mesin Teknologi Cerdas ZeroStunting AI

Solusi terintegrasi dari meja timbang akar rumput hingga pembuat kebijakan kesehatan.

INPUT CERDAS

1. Hybrid Input Engine (Multi-Modal)

  • Formulir kilat dengan otomatisasi reset & autofocus ke nama balita.
  • Voice-to-Text bahasa Indonesia untuk kader yang mendiktekan hasil.
  • Vision AI / OCR untuk scan foto KMS dan ekstraksi angka secara instan.
STANDAR DUNIA

2. WHO Anthro Precision Engine

  • Kalkulasi Z-Score real-time (BB/U, PB/U, BB/PB, LK/U, LiLA) standar WHO.
  • Klasifikasi otomatis: Severely Stunted, Stunted, Normal, Tinggi, Wasting.
  • Grafik KMS interaktif pengganti plotting manual di kertas.
EDUKASI AKSI

3. RAG LLM Local Food Advisory

  • Generative AI pemberi rekomendasi 5 jadwal makan harian balita.
  • Prioritas pangan lokal padat gizi (hati ayam, ikan kembung, telur, kelor).
  • Format edukasi WhatsApp 1-klik untuk dikirimkan langsung ke orang tua.
INTEGRASI DINKES

4. Auto-Report e-PPGBM & GIS Map

  • Ekspor rekapitulasi data bulanan posyandu sesuai format resmi Kemenkes RI.
  • Peta Sebaran Stunting Geospasial memetakan zona hijau, kuning, dan merah.
  • Pengelolaan multi-unit Posyandu terpusat untuk monitoring kepala puskesmas.

RANCANGAN ARSITEKTUR TEKNOLOGI • TKT 6 ARCHITECTURE

Arsitektur Sistem & Alur Rekayasa ZeroStunting AI

Arsitektur 4-Tier: Client Web App Mobile-First, Backend Async, Layanan AI Multimodal, dan Gov-Tech Interoperability.

TIER 1 • CLIENT & EDGE LAYER (KADER & DINKES) Next.js 16 (App Router) • TypeScript • Vanilla CSS • Local Storage Cache
Antarmuka ramah kader dengan autofocus & auto-clear, mode hemat kuota & caching, serta adaptif di smartphone Android minim spesifikasi.
TIER 2 • CORE BACKEND & COMPUTATION SERVICE FastAPI (Python 3.12) • SQLAlchemy • Supabase/PostgreSQL • RLS
Pemrosesan data multi-unit posyandu cepat, audit log otomatis, dan Row-Level Security (RLS) untuk perlindungan data medis balita.
TIER 3 • ARTIFICIAL INTELLIGENCE & ANALYTIC SERVICES Vision AI (OCR KMS) • Web Speech • WHO Anthro Engine (NumPy) • RAG Local Food
Ekstraksi data KMS fisik, dikte suara bahasa Indonesia, Z-Score akurat baku WHO, dan preskripsi gizi pangan lokal terukur (TKPI Kemenkes).
TIER 4 • GOV-TECH & INTEROPERABILITY LAYER OpenPyXL / Pandas Exporter • GeoJSON / Leaflet Engine • REST API Gateway
Ekspor laporan bulanan 1-klik 100% kompatibel format resmi Puskesmas serta visualisasi Peta Geospasial sebaran stunting per posyandu.
🔒 Prinsip Rekayasa: 100% Pure Software, Offline-First Architecture, Zero Data Leakage, dan Kompatibel Penuh Skema e-PPGBM Kemenkes RI.
