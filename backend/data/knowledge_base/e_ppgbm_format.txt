# FORMAT DAN TERMINOLOGI LAPORAN e-PPGBM (ePencatatan dan Pelaporan Gizi Berbasis Masyarakat)
# Sumber: Kementerian Kesehatan RI — Sistem Informasi Gizi Terpadu (SIGIZI Terpadu)
# Digunakan oleh: ZeroStunting AI RAG Engine

## APA ITU e-PPGBM?
e-PPGBM (elektronik Pencatatan dan Pelaporan Gizi Berbasis Masyarakat) adalah sistem
pelaporan data gizi balita secara elektronik yang dikembangkan oleh Kemenkes RI.
Kader Posyandu bertugas mengumpulkan data dan melaporkan ke Puskesmas setiap bulan.

## TUJUAN e-PPGBM
1. Memantau status gizi balita di seluruh Indonesia secara real-time
2. Mendeteksi kasus stunting, gizi kurang, dan gizi buruk lebih cepat
3. Menjadi dasar perencanaan intervensi gizi oleh Puskesmas dan Dinas Kesehatan
4. Memudahkan pelaporan dari Posyandu → Puskesmas → Dinkes → Kemenkes

---

## DATA YANG DICATAT DI e-PPGBM

### DATA IDENTITAS BALITA
- Nama lengkap anak
- Nomor induk (NIK jika ada)
- Tanggal lahir
- Jenis kelamin (L/P)
- Nama ibu/wali
- Alamat lengkap (desa, kecamatan, kabupaten)
- Nama Posyandu
- Nama Puskesmas induk

### DATA PENIMBANGAN (PER SESI TIMBANG)
- Tanggal penimbangan
- Umur dalam bulan (dihitung otomatis dari tanggal lahir)
- Berat Badan (BB) dalam kg (1 desimal)
- Panjang/Tinggi Badan (PB/TB) dalam cm (1 desimal)

### HASIL KALKULASI STATUS GIZI (OTOMATIS)
- Z-Score BB/U (Berat Badan per Umur) → Status Gizi BB/U
- Z-Score PB/TB/U (Panjang/Tinggi Badan per Umur) → Status Gizi PB/U
- Z-Score BB/PB/TB (Berat Badan per Panjang/Tinggi Badan) → Status Gizi BB/PB

---

## KLASIFIKASI STATUS GIZI (STANDAR KEMENKES RI / WHO 2006)

### BB/U (Berat Badan per Umur) — Indikator UNDERWEIGHT
| Nilai Z-Score | Klasifikasi | Kode |
|--------------|-------------|------|
| > +2 SD | Berat Lebih | BL |
| -2 SD s.d. +2 SD | Gizi Baik | GB |
| -3 SD s.d. <-2 SD | Gizi Kurang | GK |
| < -3 SD | Gizi Buruk | GBr |

### PB/U atau TB/U (Panjang/Tinggi Badan per Umur) — Indikator STUNTING
| Nilai Z-Score | Klasifikasi | Kode |
|--------------|-------------|------|
| > +2 SD | Tinggi | T |
| -2 SD s.d. +2 SD | Normal | N |
| -3 SD s.d. <-2 SD | Pendek (Stunting Moderate) | Pe |
| < -3 SD | Sangat Pendek (Stunting Severe) | SPe |

### BB/PB atau BB/TB (Berat Badan per Panjang/Tinggi Badan) — Indikator WASTING
| Nilai Z-Score | Klasifikasi | Kode |
|--------------|-------------|------|
| > +2 SD | Gemuk | Gm |
| -2 SD s.d. +2 SD | Normal | N |
| -3 SD s.d. <-2 SD | Kurus (Wasting Moderate) | K |
| < -3 SD | Sangat Kurus (Wasting Severe) | SK |

## TERMINOLOGI PENTING e-PPGBM

| Istilah | Singkatan | Arti |
|---------|-----------|------|
| Sasaran | S | Jumlah balita yang terdaftar di Posyandu |
| Ditimbang | D | Jumlah balita yang hadir dan ditimbang bulan ini |
| Naik | N | Jumlah balita yang berat badannya naik dari bulan lalu |
| Tidak Naik | T | Berat badan tidak naik atau turun |
| Tidak Datang | O | Terdaftar tapi tidak hadir bulan ini |
| Baru | B | Balita yang pertama kali ditimbang bulan ini |
| D/S | - | Cakupan penimbangan = D/S × 100% (target ≥ 80%) |
| N/D | - | Cakupan naik timbang = N/D × 100% (target ≥ 80%) |
| Prevalensi Stunting | - | (Pendek + Sangat Pendek) / Total × 100% |
| Prevalensi Wasting | - | (Kurus + Sangat Kurus) / Total × 100% |

```
Kader Posyandu
     │ Input data penimbangan setiap bulan
     ▼
Aplikasi e-PPGBM / ZeroStunting AI
     │ Hitung Z-score otomatis
     │ Generate laporan
     ▼
Petugas Gizi Puskesmas
     │ Verifikasi data
     │ Input ke SIGIZI Terpadu
     ▼
Dinas Kesehatan Kabupaten/Kota
     │ Rekap data seluruh Puskesmas
     │ Monitor prevalensi stunting
     ▼
Kemenkes RI
     │ Dashboard nasional
     │ Perencanaan intervensi
```

## TINDAK LANJUT BERDASARKAN STATUS GIZI (PANDUAN KADER)

### Gizi Baik / Normal
- Lanjutkan pemantauan rutin bulanan di Posyandu
- Berikan edukasi gizi seimbang kepada ibu
- Pastikan imunisasi lengkap sesuai jadwal

### Gizi Kurang (BB/U: -3 s.d. -2 SD) atau Pendek (PB/U: -3 s.d. -2 SD)
- Berikan Pemberian Makanan Tambahan (PMT) jika tersedia
- Edukasi ibu tentang MP-ASI bergizi, menu harian
- Pantau lebih ketat: timbang 2 minggu sekali jika memungkinkan
- Rujuk ke Puskesmas jika tidak ada kenaikan BB dalam 2 bulan

### Gizi Buruk (BB/U < -3 SD) atau Sangat Kurus (BB/PB < -3 SD)
- SEGERA RUJUK ke Puskesmas / fasilitas kesehatan terdekat
- Berikan F-100 atau RUTF jika tersedia dan atas petunjuk nakes
- Catat dan laporkan ke petugas gizi Puskesmas hari itu juga
- Follow up dalam 1 minggu

### Stunting Berat (PB/U < -3 SD) atau Wasting Berat (BB/PB < -3 SD)
- PRIORITAS RUJUKAN SEGERA
- Koordinasi dengan bidan desa dan petugas gizi Puskesmas
- Dokumentasikan dalam buku register khusus kasus gizi
- Laporkan dalam laporan bulanan sebagai kasus prioritas

## STANDAR KUALITAS DATA e-PPGBM

### Yang Harus Dipastikan Sebelum Input
1. Alat timbang sudah dikalibrasi (timbangan bayi: ketelitian 0.1 kg)
2. Alat ukur panjang/tinggi sudah dicek (infantometer/microtoise)
3. Data nama dan tanggal lahir sesuai KK/akta lahir
4. Penimbangan dilakukan tanpa pakaian tebal atau alas kaki

### Tanda Data Bermasalah (Perlu Diverifikasi Ulang)
- Z-score BB/U < -4 atau > +4 (sangat tidak lazim)
- Z-score PB/U < -5 atau > +4
- Berat badan turun drastis > 0.5 kg dari bulan sebelumnya tanpa sebab jelas
- Tinggi badan lebih pendek dari pengukuran bulan sebelumnya (tidak mungkin)
- Umur tidak sesuai dengan perkembangan fisik terlihat
